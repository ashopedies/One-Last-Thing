# Vendor-only class supplies

All amounts are editable and saved per character. Learned spells and relevant ranks control active reminders. Shopping reminders require a usable vendor location, filtered to the current locality. A sell price alone does not establish a purchase source.

| Class | Ordinary vendor presets | Other conservative checks |
| --- | --- | --- |
| Shaman | Ankh (3) | No quest totems. Fish Oil/Shiny Fish Scales qualify only if an actual vendor source is proven; not ordinary defaults. |
| Druid | Relevant Rebirth seed (3); Gift of the Wild berries/thornroot (5) | Older tiers become inactive when superseded. |
| Mage | Rune of Teleportation (5), Rune of Portals (5), Arcane Powder (5) | Light Feather only with a proven vendor source. |
| Priest | Relevant Holy/Sacred Candle (5) | Light Feather only with a proven vendor source. |
| Paladin | Symbol of Divinity (3), Symbol of Kings (5) | Spell-gated. |
| Rogue | Flash Powder (5), Thieves' Tools (1) | Blinding Powder only with a proven vendor. Finished poison families only if already carried and vendor-proven; no crafting shopping list. |
| Warlock | Infernal Stone (3), Demonic Figurine (3) | No Soul Shards or quest items. |
| Hunter | Weapon-appropriate vendor ammunition (400) | Eligible vendor pet food (10); basic quiver/pouch (1) only if no matching bag is equipped or carried. |
| Warrior | None | Custom vendor supplies remain available. |

Conditional candidates appear only when an installed database or a merchant visit positively identifies a seller. Unknown coordinates cannot produce a shopping destination. Classes added by future client versions need separate coverage.

## Hunters

Arrows follow bows/crossbows and bullets follow guns. Equipped ammunition takes priority, then the remembered item for that weapon type, then matching vendor ammunition already in bags. Change tier yourself by equipping another type. Targets never trigger an automatic price/DPS upgrade.

Pet food requires an active pet and Feed Pet. The food must match the known diet and pass native item-level checks. Initially, eligible vendor food in bags is used; choose another or disable it in Supplies. The choice is remembered by diet, including when depleted. No unknown food level is guessed to be usable.

A matching quiver or shot pouch already equipped or carried suppresses the basic bag reminder. Bag upgrades are not suggested.

## Rogues

A previously carried finished poison is remembered per poison family only when a vendor relation is proven. If the chosen item has no known vendor, crafting or Auction House acquisition is not suggested. Thieves' Tools are a utility item. Use the Supplies parent checkbox or individual item checkboxes to control reminders; item targets stay saved while unchecked.

## Existing settings

Old automatic entries outside the vendor policy are archived rather than converted into custom shopping tasks. A later verified vendor can restore their saved amounts. Player-created entries are preserved, but still require a known seller to become shopping reminders. Setting an amount to zero removes it.
